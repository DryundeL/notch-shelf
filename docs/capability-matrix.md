## Task 2: собственные разделители

PoC включается только аргументом `--section-markers-poc`. Создаёт два собственных видимых status item `│ A` и `│ B` со стабильными `autosaveName`. Ничего не скрывает, не перемещает чужие значки и не запрашивает разрешения. Сохранение позиций проверяется экспериментально; наличие `autosaveName` не доказывает устойчивость секций.

Перед запуском завершить уже работающий Notch Shelf через меню. Запуск из корня проекта:

```bash
open build/DerivedData/Build/Products/Debug/NotchShelf.app --args --section-markers-poc
```

1. Записать `sw_vers`, используемый экран и режим menu bar.
2. Удерживая Command, попробовать переместить A и B, расположить между ними доступный тестовый значок. Не использовать критичные системные элементы.
3. Выйти через меню NS, повторить команду запуска и проверить порядок всех трёх элементов.
4. Повторить на встроенном и внешнем экранах, если доступны.
5. Выйти и запустить без аргумента: A и B отсутствуют, чужие значки доступны.

## Task 3: обзор Accessibility

Статус: ожидается выбор 6–10 сторонних menu bar приложений. Проверка исходников: AX-вызовов нет; `setAccessibilityLabel` задаёт подпись собственного элемента и не обходит чужой UI.

Для каждого приложения проверить доступность элемента в Accessibility Inspector из Xcode, его роль и идентификатор, затем открытие настоящего меню через доступное AX-действие. Обычный клик мышью сам по себе не подтверждает AX-активацию. Если действие недоступно, записать ограничение без синтеза событий и private API.

Повторить идентификацию после закрытия меню, перезапуска тестового приложения и естественной смены иконки/badge, если она доступна. Не сохранять заголовки окон, содержимое меню, AX-дампы и снимки экрана; фиксировать только итоговые свойства. Не выдавать новые разрешения без явного решения пользователя. После обзора временное разрешение инструменту можно отозвать в настройках macOS.

## Task 5: решение по объёму MVP

Дата: 2026-10-31. macOS 27.0.1, build 26A434. Решение: **conceal: cancelled**. Пользователь подтвердил рекомендацию продолжить с собственной панелью без скрытия чужих значков.

Основания: discovery и AX-активация работают для части приложений; BetterDisplay возвращает OK без видимого открытия. PoC разделителей не доказывает устойчивый и обратимый conceal. Стабильность после перезапуска и badge не проверялась по решению пользователя. Gate 1: CPU и footprint измерены, полная проверка wakeups остаётся открытой. Неполные проверки не объявляются пройденными; это консервативное сужение MVP, а не go для conceal.

Задачи 17–20 отменены в текущем объёме. Уже добавленная диагностическая AX-функция остаётся отдельной, запускается явно и не становится backend скрытия. Собственная панель и настройки на публичном API продолжаются с задачи 6. Автоматическое скрытие и section reveal не обещаются без отдельной проверки осуществимости. Возврат conceal потребует нового эксперимента и отдельного решения пользователя.
