# Menu bar engine: техническая осуществимость и fallback

## Ограничение macOS
`NSStatusItem` позволяет создавать и контролировать **свои** status items, не предоставляет публичной операции «скрыть/переместить произвольный чужой item». AX может открыть часть UI-дерева, но полнота и права зависят от процесса/версии ОС. CoreGraphics не является API редактирования status items. Использование private SkyLight и синтезированных событий рискованно; не допускать инжекции, нарушения TCC/SIP.

## Уровни возможностей
| Tier | Способ | MVP status |
|---|---|---|
| 0 | Собственный `NSStatusItem` + собственная shelf | поддерживается public API |
| 1 | «Разделители» как собственные NSStatusItem, управление секциями с проверкой поведения ОС | PoC |
| 2 | AX discovery, маркировка item metadata, осторожная активация | PoC / partial |
| 3 | Snapshot icon для shelf по согласию, без continuous capture | optional |
| 4 | Private API adapter для конкретного билда ОС | experimental, выключен по умолчанию |

Никогда не рекламировать Tier 2–4 как гарантированную функцию. Нельзя считать визуальную копию status icon эквивалентом настоящего нативного item.

## Первичный PoC: чеклист
1. Создать 2 собственных разделителя; воспроизвести отделение видимой и скрываемой секции.
2. Проверить ручное перемещение test items (Command-drag, где допустимо) и их позиции после перезапуска.
3. Для 6–10 популярных приложений исследовать AX tree, идентификацию item, порядок и реакцию на click.
4. Проверить обычный click, right click, menu open, badge update, icon change, reconnect.
5. Проверить встроенный экран, внешний монитор, Full Screen и auto-hide menu bar.
6. Если невозможно надёжно открывать оригинальное меню — показывать режим section reveal, а не фиктивный item.
7. Задокументировать точный macOS build и результат на каждом дисплее.

## Contracts backend
`capabilities(forOSBuild:)`, `snapshot()`, `reveal(section:)`, `conceal(section:)`, `activate(itemID:)`, `restoreUserAccess()`; вернуть typed result `supported/unsupported/permissionDenied/transientFailure/conflict`.

## Инварианты безопасности
- Первый запуск — всё видимо, скрытие opt-in.
- При неизвестном состоянии backend не пытаться «силой» перемещать items.
- Поскольку состояние чужого UI частично непрозрачно, правила должны быть best effort и обратимы.
- Кнопка **Reveal All** и горячая клавиша аварийного восстановления.
- При изменении версии macOS private backend автоматически отключать до повторной сертификации.
- Не получать содержимое экранов для определения простой геометрии.
- Не копировать чужой исходный код без проверки GPL/других лицензий.

## Отдельная шторка
Визуальная shelf может показывать cached item representation, но действие должно транслироваться в **настоящий** доступный native item или reveal его в menu bar. Если это не работает, помечать значок как «Открыть секцию», не имитировать click.
