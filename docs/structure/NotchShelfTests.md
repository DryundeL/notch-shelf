# NotchShelfTests

Unit-тесты XCTest; target подключён к общей схеме, тестовых методов пока нет.
Тесты добавляются вместе с логикой: ShelfState (6), Geometry (7), SettingsStore (10), recovery (13), дисплеи (14).
Использовать детерминированные snapshots и подмены Ports, без TCC и управления реальными чужими значками.
`TestScaffold.swift` — только место для будущих тестов; успешная сборка не доказывает поведение продукта.
