# NotchShelfUITests

XCUITest target подключён к общей схеме; сценариев пока нет.
Здесь будут проверки запуска agent, выхода через меню, клавиатурной навигации и окна настроек.
Физические мониторы, Spaces, TCC и sleep/wake проверяются также вручную по 10-testing.md.
Не сбрасывать TCC и не менять настройки пользователя автоматически.
