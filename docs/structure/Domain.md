# Domain

Чистые модели и политики, без AppKit, системных вызовов и побочных эффектов.
Зависимость — Foundation; геометрия использует доступные через него типы CGRect/CGFloat.

- `ShelfState.swift`: автомат панели, задача 6.
- `Geometry.swift`: расчёт координат и ограничение рамками экрана, задача 7.
- `DisplaySnapshot.swift`: неизменяемое описание дисплея, задача 14.

Файлы пока содержат только описание. MenuItem и RulesEngine добавляются после go/no-go задачи 5.
