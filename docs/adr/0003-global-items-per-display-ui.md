# ADR-0003: Глобальная модель status items + UI per-display

**Status:** Accepted.

## Context
Menu bar визуально присутствует на разных экранах, но OS не обещает полностью независимые управляемые item sets на каждом дисплее.

## Decision
Глобальный registry/rules; профили интерфейса и anchor/window routing по дисплеям. Один переиспользуемый NSPanel.

## Consequences
Предсказуемые правила, меньше памяти; нельзя обещать независимое расположение каждого значка на каждом экране без отдельного доказанного backend.
