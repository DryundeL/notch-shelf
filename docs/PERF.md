# Измерения производительности

## Gate 1 — 2026-10-31

Среда: macOS 27.0.1 (26A434), Mac16,12, RAM 16 GiB. Release, Swift 6, deployment target macOS 14.0, без debugger и без аргумента PoC. Сборка `CODE_SIGNING_ALLOWED=NO`: BUILD SUCCEEDED.

Запущен отдельный Release-процесс. Протокол: 60 секунд стабилизации, затем `top -l 61 -s 5` с CPU, MEM и IDLEW; первый отсчёт CPU исключается. `footprint` до и после окна idle. RSS не подменяет phys_footprint. Числа будут внесены после завершения замера; текущий статус не означает прохождение Gate 1.

Исходники не оптимизировались. Доступ к системным метрикам внутри песочницы запрещён; замер выполняется с явно разрешённым выходом из неё.

Результат: 60 интервалов после исключения первого отсчёта. CPU median 0.0%, p95 0.0%, max 0.0%. phys_footprint baseline/end/peak: 13 MB / 13 MB / 13 MB (единицы и округление footprint сохранены). Монотонный рост на этом прогоне не обнаружен.

IDLEW в top: 2. Это вспомогательное наблюдение, не измерение всех timer wakeups/sec через Instruments. CPU укладывается в ориентир; память ниже верхнего ориентира 30 MiB. Полная приёмка wakeups остаётся открытой до Instruments. Прогон не подтверждает работу под macOS 14 и не заменяет повторные замеры. Исходные локальные выводы: `/tmp/notch-idle-top.txt`, `/tmp/notch-idle-footprint-baseline.txt`, `/tmp/notch-idle-footprint-end.txt`.


## Текущий код — базовый idle, 2026-11-01

Среда: macOS 27.0.1 (26A434), Mac16,12 / Apple M4, RAM 16 GiB. Чистая Release-сборка (-O), ad-hoc подпись, обычный hardened runtime, без отладчика и тестовых модулей. Установленная Debug-копия не заменялась. До запуска других процессов NotchShelf не было. SHA-256 бинарника и исходных файлов записаны в [environment.json](perf/2026-11-01-current-idle/environment.json); код содержит незакоммиченные изменения проекта, поэтому HEAD сам по себе не идентифицирует измеренную версию.

Сценарий: закрытая шторка, без выбранных приложений и AX-сканирования. Параметры `-shelf.settings '{}' -shelf.visibilitySessionActive NO` переопределяют настройки только в NSArgumentDomain тестового процесса. Постоянный выбор приложений не менялся; TCC не изменялся. После 60 секунд прогрева — `top -l 61 -s 5 -pid <PID> -stats pid,cpu,mem,idlew,threads`. Первый отсчёт отброшен; осталось 60 интервалов, 5 минут. p95 — nearest rank (57-й элемент отсортированной выборки). `footprint -p <PID> -f bytes --noCategories` выполнен до и после окна выборки.

CPU ниже ориентира p95 < 1%, footprint ниже верхнего ориентира 30 MiB. Это один прогон базового режима на рабочем компьютере; рост 272 KiB не доказывает утечку, а низкие значения не доказывают её отсутствие. Шторка с выбранными приложениями, 20 значков, 100 циклов, hotplug, sleep/wake и настройки в этом прогоне не измерялись. IDLEW из top сохранён в исходных отсчётах, но не пересчитан в wakeups/sec; приёмка этого показателя требует отдельного trace Instruments. Фоновая нагрузка системы не контролировалась.

68 unit-тестов прошли в оптимизированной Release-конфигурации с `ENABLE_TESTABILITY=YES ENABLE_HARDENED_RUNTIME=NO`, необходимыми для загрузки локально подписанного XCTest. Это не побитово та же сборка: после тестов измеряемое приложение пересобрано `clean build` без этих переопределений. Первые попытки тестового запуска не прошли из-за выключенного @testable и несовместимости подписи тестового модуля с hardened runtime; настройки проекта не менялись. UI-тесты не запускались.
